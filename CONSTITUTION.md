# Kairos Constitution

1. **Observation over Authority** — Kairos trusts what you see, not what a map or database says.
2. **Offline by Default** — No internet, GPS, or cloud sync is ever required.
3. **Modular and Optional** — Use time, food, energy, or any combination.
4. **Open and Verifiable** — All source code and references are public and auditable.
5. **Forkable but Honest** — You may fork Kairos, but any version that adds dependencies on external authority must clearly state that divergence.
6. **For All Humans** — Interfaces must be simple enough for a child and robust enough for a programmer.
7. **Gregorian as Reference, Not Center** — The conventional calendar is shown only as a small optional footnote.
