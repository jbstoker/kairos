# How to Contribute to Kairos

**Thank you for wanting to help!**

Kairos is open source, free, and forever. It belongs to everyone who uses it.

---

## Ways to Contribute

### 1. Add Data
- **Plants**: Add a new plant to the seasonal data (`data/seasonal_data.json`).
- **Festivals**: Add a new festival or celebration.
- **Traditions**: Add a new tradition (e.g., Tartarian, Celtic, Vedic, etc.).

### 2. Improve the Code
- Fix bugs.
- Improve the UI/UX.
- Add new features (e.g., planetary positions, voice output).

### 3. Improve the Documentation
- Update the README.
- Add new wiki pages.
- Translate the interface into other languages.

### 4. Share and Observe
- Use Kairos in your daily life.
- Share your observations with the community.
- Help others learn how to use Kairos.

---

## How to Submit

1. Fork the repository.
2. Make your changes.
3. Submit a pull request.
4. Wait for review (we will respond within a week).

---

## Code of Conduct

- Be respectful.
- Be constructive.
- Be honest.
