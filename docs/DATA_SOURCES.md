# Kairos Data Sources

## Time Data
- **Solar/Lunar calculations**: Skyfield, Meeus algorithms, SunCalc
- **Checksum**: Precession cycle (25,772 years)
- **Ephemeris**: JPL DE440 (local, optional)

## Phytochemical Data
- **Primary source**: USDA FoodData Central (public domain)
- **Secondary sources**: PubChem, Phytochemical Database
- **Disclaimer**: All databases contain errors and variations. Use as a reference, not a prescription.

## Traditions
- **Tartarian, Celtic, Vedic, Mystical**: Modern interpretations, clearly labelled as optional layers.

## User Data
- All user observations and additions are stored locally.
- No data is sent to any server.
